## Consigne

Montrer au tableau, avec un objet réel dans la main, ce que donne « je tourne puis j'avance » et « j'avance puis je tourne », en partant du même point. Puis montrer les deux résultats de mon programme.

## Matériel

Je peux prendre un objet comme un livre ou un téléphone, pour que l'orientation se voie. Une table ou le tableau avec un point de départ marqué à la craie. L'ordinateur avec le programme de l'exercice 3 de la série 5 pour les resultats.

## Les exécutions 

Entrée où les deux ordres diffèrent, rotation d'un quart de tour autour de l'axe vertical et translation d'un mètre vers la droite :
1 0 0 0 0.7071067812 0 0.7071067812 1 0 0

Sortie:
1.0000 0.0000 -1.0000
-0.0000 0.0000 -2.0000

Entrée où les deux ordres donnent le même résultat, même rotation mais translation d'un mètre vers le haut, donc portée par l'axe de rotation :
0 1 0 0 0.7071067812 0 0.7071067812 1 0 0

Sortie:
-0.0000 1.0000 -1.0000
-0.0000 1.0000 -1.0000

## Constat 
« Même rotation, même translation, même point de départ. Seul l'ordre a changé, et l'objet n'est pas au même endroit. Dans une pose, l'ordre n'est pas une convention d'écriture, c'est une règle : on tourne d'abord, on déplace ensuite. »
